# Ringlet

A radial action ring for files selected in the macOS Finder. Hold a shortcut (or a mouse button), flick toward an
action, release. First actions: convert HEIC photos to JPG or PNG, next to the originals, metadata kept.

> Work in progress. macOS 14+, Swift 6, no dependencies. MIT license.

---

**FR** — Un anneau d'actions pour les fichiers sélectionnés dans le Finder. Maintiens un raccourci (ou un bouton de
souris), pars vers une action, relâche. Premières actions : convertir des photos HEIC en JPG ou PNG, à côté des
originaux, métadonnées conservées.
